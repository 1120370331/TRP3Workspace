## 验收结果

在独立目录 `.test-output/fireworks-frozen` 中冻结源码后，以下入口累计94项通过：构建测试15、引擎45、庭院游戏8、Scene3D 5、三维粒子6、魔方15。原有测试中的源码哈希检查按构建器的LF规范化规则核对，避免把Windows换行误判为过期产物。

魔方完整包通过AceSerializer回读与上游TRP3 ScriptGeneration沙盒启动，能接收转层输入并关闭。新增验证包括三维运动/环形发射、共享生成预算、优先级淘汰、粒子池复用、父节点跟随与孤儿清理、近远裁剪、视距缩放、粒子不参与拾取、缓存投影与全新场景逐点一致、暂停/停止，以及四阶段对照保持局面和解谜时间。

手动复原和回放复原触发一次五式烟花，载入已完成存档不重播。烟花包括礼花、星环、金柳、喷泉和连环爆裂；试验台提供密度档位、单式/组合燃放、24秒四阶段对照、停止与日志导出。预算为1536粒子、24发射器、每步768次生成，渲染继续保留几何配额。

本地实际Lua绘图预览完成七阶四阶段对照，观察到高档达到1536粒子预算并计入丢弃，结束后清场。固定1.9秒帧检查了火花、星环、喷泉的空间位置和与魔方的遮挡。预览将原生star4纹理近似为渐变光点，不是客户端像素验收。

## 性能边界

同一组本地转层CPU采样，四阶投影+绘制均值12.47 → 3.17 ms，七阶65.97 → 10.83 ms，七阶原生属性设置调用减少约73%。没有删减魔方几何。详细方法及原始数据见 [性能对比](../../performance/README.md)。这是mock宿主的算法对比，不是WoW FPS。

WoW客户端的实际帧率、原生星光纹理、鼠标捕获与重载持久化仍待实机确认；构建报告维持 `inGameVerified=false`。建议使用此固定包在4/7阶分别运行烟花对照并导出NDJSON。
