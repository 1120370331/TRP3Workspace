# 空间移动、粒子控量与奥术光效

游戏 **0.5.0-test / objectVersion 7**，共享引擎 **0.5.0**。复制 [item.t3e.txt](item.t3e.txt) 的完整内容导入TRP3 Extended；沿用rootId `0908ArcCube001`与原存档格式，保留完整海潮皮肤，无需外部素材包。

## 体验入口

- **材质试验 → 空间运动**：依次切换关闭、模型平移、镜头平移/推进。模型穿越视口时自动剔除绘制，世界空间拖尾继续沿原轨迹运动。
- **材质试验 → 光效**：轮廓光、自发光脉冲、距离雾。光效是原生颜色接口的逐源面近似，不是自定义GPU shader，不新增几何面片。
- **烟花试验 → 自动控量**：普通烟花默认开启，过载时降低绘制数量与覆盖面积。模拟、随机种子、发射数量和奖励逻辑保持不变。
- **四阶段对照**：临时固定全量策略，结束或中断后恢复开关；日志包含本次策略，避免动态降质影响负载比较。

## 本地基准

[benchmark.json](benchmark.json) 使用同一份基准脚本，以0.4.3固定候选中的场景与粒子模块为基线。每组60帧，前6帧不计入耗时；不是WoW FPS或GPU计时。

| 场景/工作量 | 之前 | 现在 |
| --- | ---: | ---: |
| 32个像素模型与镜头移动，Lua均值 | 15.44ms | 1.65ms |
| 满池1024粒子，每步再请求768粒子，Lua均值 | 22.15ms | 0.37ms |
| 移动轨迹投影节点次数（60帧） | 1920 | 148 |
| 移动轨迹皮肤顶点变换次数（60帧） | 737280 | 56832 |

移动场景的顶点与颜色量化到7位小数后哈希相同；饱和粒子场景生成结果相同。移动轨迹包含大量屏幕外物体，不能把该倍数推广到所有模型始终可见的场景。满池收益来自同优先级拒绝不再反复扫描活粒子；真正的高优先级替换仍需寻找淘汰目标。

自适应每秒判断，过载下降一级、最低25%额度；持续3秒恢复到目标帧耗时附近才回升。粒子被省略绘制后仍照常模拟，所以该策略主要节省投影后的提交与叠加成本。模型基础几何与空间查询仍有成本，没有新增完整空间树或GPU渲染后端。

复测命令：`python tools/benchmark-spatial-effects.py`。通用接口和参数见 [3D指南](../../../../docs/ITEM-GAME-3D.md)。
