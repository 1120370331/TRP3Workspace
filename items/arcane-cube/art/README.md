# 海潮奥术：内嵌点阵材质

当前六幅图案已直接用于魔方默认皮肤：上/下/左/右/前/后分别为海晶、月潮、海贝、潮汐戟、潮涌、漩涡。每幅图案覆盖一个整面，各小方块只取对应UV片段。原始UV基于不随转层改变的home坐标，因此不会在转动后重新分配图案。

Imagegen只生成[六面美术参考](references/tidal-six-faces.png)，随后根据浪潮、海贝、三叉戟、漩涡、水晶、新月的风格，用整数图形重新绘制24×24点阵。没有把参考图缩小、采样或贴到模型上。

单面原尺寸PNG分别为 [潮涌](pixels/wave.png)、[海贝](pixels/shell.png)、[潮汐戟](pixels/trident.png)、[漩涡](pixels/whirlpool.png)、[海晶](pixels/crystal.png)、[月潮](pixels/moon.png)。PNG与SVG均用于制作和检查；游戏不会读取它们。

## 数据与绘制

六面共3456个像素，共享12色调色板。RLE4使用一个可打印字符表示“4位颜色索引 + 2位游程长度”，每个游程覆盖1–4像素。调色板与编码数据共1941字节，相比原始RGB的10368字节减少约81%；完整 `pixel-art.lua` 为2423字节，TRP3导出时还会整体压缩。

运行时只解码一次，并将相邻同色像素合并为矩形。本组点阵合并为990个色块。绑定时将矩形经UV映射到模型局部表面：完整矩形UV使用仿射快速路径，三角形或一般四边形按UV三角域裁剪。模型、父节点和摄像机变换由现有三维管线处理。原始网格继续负责拾取和碰撞，色块仅用于显示。

这是用彩色面片模拟纹理采样，不是GPU图片纹理。材质试验默认三个主体共2598个显示面，默认视角1080个可见Texture面片，受4096面预算约束。引擎0.4.3将同一源面的色块合并到共享Frame，默认视角只需7个原生Frame，Texture和像素细节不变。这里的面片数不等于GPU draw call数；WoW帧率需实机测量。切换材质若超出预算会保留原绑定，不使模型消失。

## 使用

进入魔方后点击“材质试验”。海潮符文匣默认每面使用不同图案，潮汐方碑测试拉伸与矩形UV，仪式晶石测试三角面的裁剪。

正常游玩时无需点击材质试验：默认已穿戴海潮皮肤，阶数右侧可切换经典六色。测试覆盖2–7阶每面UV总覆盖面积恰好为1、每面片段数等于N²，以及转层期间不重新烘焙/分配片段、读档保留原片段。

选择主体后，可以更换六种图案、恢复六面组合、旋转UV、自转主体、旋转父节点或解除绑定。返回魔方会恢复原局面和视角，试验期间不增加解谜计时。关闭或重开不会把试验场景写进魔方存档。

制作源在仓库 `tools/build-tidal-pixels.py`；它是可编辑的整数图形定义。运行 `npm run build:tidal-pixels` 会重新生成Lua、PNG和SVG，修改SVG预览不会反向修改Lua。打包运行 `npm run build:cube`；不需要额外素材包或客户端图片安装。
