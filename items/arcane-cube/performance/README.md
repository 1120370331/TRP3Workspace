# 高阶魔方渲染对比

针对四阶以上明显变慢的问题，固定每个阶数的Y轴外层转动轨迹，运行36个角度，前6帧预热，统计后30帧。使用实际Lua 5.1场景与WoW适配器，加上仓库mock宿主；原生属性设置方法加计数包装。下表是本次本机采样，**不是WoW客户端帧耗时或FPS**。

| 阶数 | 优化前：投影+绘制均值 | 优化后 | 减少 |
| --- | ---: | ---: | ---: |
| 3 | 6.57 ms | 1.63 ms | 75% |
| 4 | 12.47 ms | 3.17 ms | 75% |
| 5 | 22.07 ms | 4.83 ms | 78% |
| 7 | 65.97 ms | 10.83 ms | 84% |

七阶36帧中的原生属性设置调用从511372降至139199，减少约73%。几何未删减：仍为219节点、2190提交面、默认视角1095可见面。变化来自节点/父子变换缓存、按节点复用投影、视锥内快速路径、法线缓存、稳定面ID绑定和按需设置原生属性。独立回归测试将缓存结果与新建场景的结果逐点比较，覆盖父子旋转与摄像机变化。

原始数据：[优化前](render-before.json) · [优化后](render-after.json)。优化前数据是本任务修改前的观测记录；当前命令重现优化后的实现，不自动切回旧源码。

```powershell
python tools/benchmark-scene3d.py > render-cpu.json
```

计时来自Lua `os.clock`，短区间有时钟量化和本机调度波动；应关注同工作负载下的大幅变化，不把小数位当作精密GPU计时。新运行还记录相关源码文件的规范化SHA-256。

烟花台另提供运行在WoW宿主中的四阶段真实负载对照；需要在客户端导出NDJSON，核对 `hostKind`、阶数、镜头、粒子预算、帧P95和丢弃数。浏览器mock的固定FPS不可用于证明客户端性能。
