## 暂停与退出

- **Esc**：打开暂停菜单；在设置页面按 Esc 返回暂停菜单，不退出战局。
- **游戏设置**：分别切换背景音乐、游戏音效及1×/2×速度，设置即时保存；“昼夜配乐 / 试听”可预听两首原生曲目。底部“音乐”可直接进入同一页面。
- **保存游戏**：保存后继续停留在暂停菜单。
- **退出本局**：普通关直接放弃当前关卡并返回地图，不记录失败；无尽挑战立即结算当前轮次与积分。
- **返回地图（保留）**：保存当前战局并返回庭院地图，之后可以继续。
- **保存并关闭游戏**：写入成功才关闭整个游戏窗口；失败保留窗口与战局。
- **右上角红叉**：保存、暂停并收起窗口；再次使用道具回到同一场次的暂停菜单。保存失败不会收起。
- **继续游戏**：恢复战局。收起和暂停期间敌人、冷却、毒雾阶段和弹体不推进。

大多数单位数字为 **PetSpeciesID**，通过宠物日志 API 取得带皮肤的 DisplayID；经典憎恶与新版巫妖均使用包含皮肤配置的 **CreatureDisplayID**，不再直接加载裸 M2。映射见 [abomination-skin.json](research/abomination-skin.json) 与 [lich-skin.json](research/lich-skin.json)。其他源表证据见 [research/model-skins.json](research/model-skins.json)，地面与模型路径出处见 [research/native-candidates.json](research/native-candidates.json)。

## 项目与共享引擎

```text
items/garden-defense-wow/
  item.json          本版独立身份，引用 ../../framework/item-game
  content.json       关卡/规则配置、原生纹理/模型目录、visuals 映射
  game.lua           本版的规则、流程和存档
  src/ui.lua         本版地图、单位表现、卡牌、工具、菜单与弹窗
  src/enemies.lua    独有敌人的技能状态、远程弹体和持续伤害
  src/progress.lua   当前存档统计、成就条件和数据升级
  src/progress-ui.lua 统计与成就双页签
  research/          资源出处
  tests/             离线 API 合约检查
  dist/              编译生成的完整导入代码
```

本版从像素版 0.1.1 的玩法源码建立独立分支，便于后续继续改造。没有携带像素图形模块，也不把本游戏的地图和植物知识写入引擎。`game.lua` 仅通过 `ctx` 使用引擎；编译时从 `item.json.engine` 读取共享源码，连同本版 UI 与内容一次性装入道具。

通用引擎新增 `surface.draw` 的 `texture` / `model` 节点、贴图平铺/UV裁剪/着色/混合、模型镜头/朝向/动画、资源池与图标回退。满草坪 45 株植物、48 个敌人和5台机械防线为98个模型；本版模型对象预算为104。弹体使用贴图，不为每颗弹丸新建模型。

单位通过共享 ModelScene 的独立 Actor 加载完整皮肤，读取冻结待机姿态的 `GetActiveBoundingBox`（不可用持续0.5秒才退回 `GetMaxBoundingBox`）计算缩放与脚底对齐。显示ID及边界按资源缓存，避免重复查询和攻击时缩放抖动。模型的 `render.width/height` 是目标体型，不创建单格取景框；场上生物和机械防线待机包围盒宽度不超过109.2、高度不超过88.4，即84×68格子的1.3倍；攻击动画伸出的部分允许超出。寒霜精灵为92×84，腐化巨尸为106×88。

调整单位时修改 `content.json.assets.models.<模型名>`：

| 参数 | 效果 |
| --- | --- |
| `render.width / height` | 待机模型的目标像素宽高，保持原比例，宽或高贴合限制 |
| `scale` | 整体体型倍率，默认1；与辉光孢子成长倍率相乘，再受1.3格上限约束 |
| `render.offsetX / offsetY` | 脚底的像素偏移，默认0；正数向右/下，独立于体型，不改变格子和攻击判定 |
| `modelAnchor` | 可选模型局部脚底 `{x,y,z}`，供原点特殊的资源校准；通常无需设置 |

例如 `render: {"width":90,"height":80,"offsetX":0,"offsetY":-4}`、`scale:0.8` 会将目标体型调整为72×64，脚底上移4像素。新配置使用 `fitFill:1`，不再额外缩小18%；模型按原生投影拟合，保持脚底不漂移。重新运行 `npm run build:garden-wow` 后导入新包才能生效。

所有战场单位共用一个完整画布镜头。按脚底 `depth` 分组，为不同行分配互不交叠的深度区间，同排单位共用区间；下方单位在前，上方在后。使用0.55弧度视角，每逻辑像素映射0.01模型单位，补偿远近透视，不再把镜头放到60000之外。清除场景雾并允许原生模型重叠。格子没有各自的模型视口，点击区域没有背景绘制，模型透传鼠标，菜单高于场景。守卫配置为朝右，敌人朝左，向日葵正面展示。

版本11不再用固定的世界 Y 方向和垂直视角公式定位。对每个深度平面调用 `Project3DPointTo2D`，结合 `GetEffectiveScale` 获取真实投影方向和单位像素比例，反算目标格子脚底的模型位置。模型尺寸同样按原生投影换算，并检查边界八角的最终屏幕尺寸；镜头初始化仍用上述常规参数。资产用 `screenFacing` 定义屏幕方向、`forwardYaw` 定义模型自身的前向轴，不再统一硬套一个旋转角。

Actor 原生变换也会将 `SetPosition` 的平移乘以模型缩放。因此目标世界位置必须先除以当前 Actor 缩放，再叠加模型自身的脚底偏移；不能把已缩放的世界位置直接交给 `SetPosition`。体型变化、辉光孢子成长、前排模型增减引起的透视补偿，都不会再移动单位的格子锚点。

从存档选择页预热完整模型目录，一次推进4种资源加载；场上需要的资源直接请求，不等待预热队列。检查 Actor `IsLoaded`，在原生几何完成一帧身份变换后再读取有效边界，避免缓存加载中或上一姿态的尺寸；不能额外等待 `IsGeoReady`，该值在实机模型和边界已就绪时仍可持续为false。`E.readModelBounds` 统一六数值和双向量返回格式，优先读取冻结待机边界。场景持续更新，手动暂停仍允许资源与投影就绪。加载超时只记录诊断并继续重试，不再自动暂停战局；Esc和红叉行为保留。接口依据见 [research/model-rendering.md](research/model-rendering.md)。

场上敌人使用1–48的稳定显示槽，删除数组中的一个敌人不会让后续敌人换模型。隐藏 Actor 优先按相同资源复用，最多保留120秒，池满时回收空闲 Actor；预热与场上单位共用104个对象的预算。关闭时清除模型，已解析的显示ID及边界可供本引擎会话重新打开时复用。引擎的默认独立模型显示模式仍供其他游戏使用。没有操作客户端实测，也不声称已经测得实际加载耗时改善。

邪恶南瓜娃娃可吞掉正在啃咬前一格守卫的敌人。黑索微型地雷武装12秒后使用与僵尸啃咬相同的38像素接触边界引爆，并秒杀范围内目标。阳光和界面音效走 Master 通道，不受 SFX 单独关闭影响，仍遵守总音量和游戏内音效开关；高优先级反馈可抢占普通命中音，避免密集战斗吞掉拾取提示。

近战周期为疾行恶鬼0.65秒、普通敌人0.8秒、巨尸与缝合怪1秒；前40%为前摇，到命中点只扣一次血，然后收招。每次伤害为原每秒伤害乘周期，持续输出强度保留。`melee` 配置同时驱动攻击动画采样和伤害时间；暂停、2倍速、读档使用同一战局时间。目标离开或进入呕吐/僵直会取消近战。具体皮肤的挥击姿态仍需由用户在客户端观察，离线检查只能证明时钟和结算一致。

自然、寒霜、孢子、暗影与啃咬命中共享一路声音预算。按1.5秒时间常数平滑事件密度，播放间隔为 `0.55 + min(0.7, 密度 × 0.035)` 实时秒；不排队补播，2倍速不缩短声音间隔。吞噬、爆炸和机械碾压保留更醒目的独立反馈。呕吐声音最多一路，播放1.4秒后淡出，并让普通战斗音让出1.6秒；拾取与菜单声音保留独立预算。不修改魔兽全局音量。

## 统计和成就

从庭院地图或暂停菜单点击“统计 / 成就”。查看页面时暂停战斗，返回会恢复进入前的状态；按 Esc 则进入暂停菜单。

统计包括战斗时长、开局、胜败、击杀、收集与消耗阳光、部署守卫及种类、割草机出动、无割草机胜利、通关数和各关最快时间。战斗时长不计菜单和暂停时间，2倍速按实际模拟推进所消耗的正常时间累计；各关最佳时间按战局逻辑时间记录。

10项成就覆盖首次种植、首次胜利、无割草机胜利、百次击杀、千点阳光、全部守卫、半程及全通关、消灭憎恶和亡灵师。解锁时显示提示，读档不重复结算。统计与成就自动写入各槽 `progress`，删档一并删除；旧存档继承可确定的通关进度，其余历史数据不补造。成就不额外发放金币或道具。

## 构建

仓库根目录首次执行 `npm ci`。之后在本项目目录执行：

```powershell
npm run build
```

或在仓库根目录执行 `npm run build:garden-wow`。构建会统一 Lua 的 LF 换行，避免 Windows CRLF 导致 TRP3 外层工作流 `unfinished string`。源码和引擎哈希见 `dist/build-report.json`。

材质配置在 `content.json.assets.textures`，单位模型及镜头在 `assets.models`，植物/敌人/工具映射在 `visuals`。后续更换皮肤只改本版，不需要修改像素版或引擎内部。

存档写入本道具实例的 `IG_SAVE_V1`，备份由引擎保存在 `IG_SAVE_BACKUP_V1`。建档、读档、删档、暂停和通关同步核对写入；战局每5秒保存、种植/收阳操作合并保存。WoW 在正常退出或 `/reload` 等时机将这些数据写入磁盘。
