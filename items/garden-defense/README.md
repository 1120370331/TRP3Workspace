# 植物大战僵尸 · 艾泽拉斯庭院（像素版）

本项目保留为像素版。[魔兽材质模型版](../garden-defense-wow/README.md)另有独立目录、道具 ID 和存档。

当前版本：`0.2.0-test` / 对象版本 **3**。随共享 ItemGame 0.2.0 引擎重新构建，保留 Windows 换行修复；像素版玩法与存档格式不变。已导入旧版时，重新导入完整新版，再执行一次 `/reload` 后使用；根 ID 和存档版本保持不变，不需要删档或重新建档。

独立的 TRP3 Extended 游戏项目。草坪、十关地图、种子栏、植物和僵尸造型、战斗界面、存档菜单均由本项目提供。共享引擎位于 `../../framework/item-game`；源码阶段不在游戏目录复制引擎，编译导入代码时才合并。

## 项目结构

```text
items/garden-defense/
  package.json           本项目的构建命令
  item.json              身份、发布版本、共享引擎路径、游戏模块清单
  content.json           十种植物、六种敌人、十关与全部波次、音效
  game.lua               种植、战斗、波次、解锁、三个存档槽和自动保存
  src/
    ui.lua               项目自己的地图、草坪、种子栏、菜单和弹窗
    sprites.lua          项目自己的像素造型与调色板
  research/              Terra 搜集的 WoW 音效、模型 ID 与来源
  tests/test_game.py     游戏行为检查，按需由开发者运行
  dist/                  构建生成，不手改
```

`game.lua` 返回 `function(ctx, modules)`。`ctx` 来自引擎，`modules.ui` 和 `modules.sprites` 来自清单声明的游戏模块。UI 读取表现状态，通过 actions 调用游戏操作；关卡和存档规则不进入引擎。引擎新增的 `ui.surface` 是通用有界画布，`save.flush` 是通用同步保存接口，可供其他游戏使用。

## 构建和导入

首次在仓库根目录安装构建依赖：`npm ci`。随后在本项目目录执行：

```powershell
npm run build
```

也可在仓库根目录执行 `npm run build:garden`。构建器从 `item.json.engine` 读取共享引擎，从 `item.json.modules` 读取本项目模块，连同入口与配置生成完整道具。生成过程包含 Lua 5.1 语法校验、结构回读与哈希记录，不启动游戏。

将 [dist/item.t3e.txt](dist/item.t3e.txt) 的**完整内容**粘贴到 TRP3 Extended 的导入框，导入后添加到 TRP3 背包，右键“进入庭院”。不需要另装引擎道具、素材包或 Musician。

目标为 TRP3E build 1061 / 2.3.5，已按本机安装源码核对。当前发行是候选版；按用户要求停止实机测试，本次交付不声明已在魔兽中验收。共享引擎升级后重新运行构建命令，即可将最新引擎带入新导入包；给其他玩家发布更新时保留 rootId，并递增 objectVersion。

## 玩法

点击种子卡，再点草坪种植。点击阳光或“收阳”增加阳光；铲子移除植物且不退款。每条开放路线有一台一次性割草机，僵尸穿过已用过割草机的家门即失败。清完本关所有波次后胜利，可重试、返回地图或进入下一关。

新存档从豌豆射手起步，每关开放原版顺序的下一种植物，解锁永久保留。第九、十关是夜间，天空不掉阳光；蘑菇在白天睡觉。通关奖励为本游戏金币，保存在当前存档槽内，不修改魔兽金币或其他 TRP3 道具。

## 存档

三个槽各自保存已通关关数、金币和完整战局。战局含植物生命、产阳/攻击计时、种子冷却、敌人生命/减速/撑杆状态、弹体、场上阳光、割草机、波次和随机序列。

- 建档、读档、暂停、返回地图、通关和手动保存会核对写入结果。
- 种植、收阳等操作合并保存，正常战局每5秒自动保存，关闭时由引擎再保存。
- 读档后的进行中战局先暂停，点击“继续游戏”恢复。
- 删档需要游戏内二次确认。建档和删档写入失败会回退内存操作，其他槽保留。
- 主存档写入道具实例的 `IG_SAVE_V1`，上一版本由引擎保留在 `IG_SAVE_BACKUP_V1`。存档格式不匹配或内容无效时保留原值并停止启动。

写物品变量是修改客户端内存中的 TRP3 数据；魔兽在正常退出或 `/reload` 时写入 SavedVariables。不要堆叠或丢弃主道具。

## 素材与实现依据

可辨认的植物和敌人像素造型由本项目手工定义，运行时用引擎矩形节点绘制。播种、收阳、命中、爆炸、警报与胜负使用可关闭的原生 SoundKit 候选，音效失败不阻断玩法。模型候选留在 `research/`，没有把未验证模型作为运行依赖。

参考阅读：[G43riko/PlantsVsZombies 的 plants.js](https://github.com/G43riko/PlantsVsZombies/blob/master/plants.js)（MIT），用于对照格子定位、同路射击和产阳循环；本实现使用引擎固定步长与可序列化计时，不复制其代码或素材。声音/模型来源见 [research/wow-assets.md](research/wow-assets.md)。
